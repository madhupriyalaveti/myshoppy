# 🛍️ MyShoppy - Mobile First E-Commerce Application

## Project Overview

MyShoppy is a mobile-first e-commerce application developed using React Native and Expo. The application enables users to browse household products, search products, manage a shopping cart, maintain a wishlist, and complete the checkout process through an intuitive and user-friendly interface.

This project was developed as part of the Capstone Project.

---

## Features

- Splash Screen
- Home Screen with promotional banner
- Product Categories
- Product Search
- Product Sorting
- Product Details
- Add to Cart
- Wishlist Management
- Quantity Update
- Shopping Cart
- Checkout Process
- Order Success Screen
- User Profile
- Responsive UI Design
- Pull-to-Refresh Support

## Installation

Clone the repository or extract the project folder.

Install dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npx expo start
```

Run the application using:

- Expo Go (Android/iOS)
- Android Emulator
- iOS Simulator
- Web Browser
